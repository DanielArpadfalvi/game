# Bajnok-assetek (Data Dragon)

Ide kerülnek a valódi bajnok-képek. A képfájlokat NEM verziózzuk (Riot-tulajdon),
töltsd le a repo gyökeréből:

    npm run fetch-assets

Ez létrehozza:
  Ezreal.png, Ezreal_load.jpg, Ryze.png, Ryze_load.jpg, ... (Ziggs, Ashe, Lux, Vayne)

A játék automatikusan bekötí ezeket. Ha hiányoznak, placeholder grafikával fut.
